# AUREVA 0.1.4 — manual acceptance checklist

- [ ] Popup opens without a Content Security Policy inline-script error.
- [ ] Dashboard query mode is initialized through local `view-mode.js`.
- [ ] Full-tab mini-app displays only one vertical scrollbar.
- [ ] Sticky header/navigation remain usable during scroll.
- [ ] Plant hero, real-world weather, browsing points and care actions have the intended colour hierarchy.
- [ ] Popup, mini-app and dashboard remain visually consistent.
- [ ] Check keyboard focus and reduced-motion behaviour.
- [ ] Verify weather city entry, refresh and visible provider attribution.
- [ ] Verify Focus, protection, coach and setup screens remain functional.
- [ ] Verify existing data is retained after upgrading an unpacked installation.

Automated tests are not a substitute for this manual Chrome verification.
