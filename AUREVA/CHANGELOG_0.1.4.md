# AUREVA 0.1.4 — changelog

- Removed inline script from popup HTML; local external `view-mode.js` now handles dashboard query-mode setup under Manifest V3 CSP.
- Removed nested vertical scrolling from the full-tab mini-app; the document viewport is the single vertical scroll owner.
- Added `aureva-polish.css` as the final visual hierarchy layer.
- Retained current colour values; clarified usage by role: plant = plum/violet, outside weather = sky/mint, digital-life selection = lavender/periwinkle, care = restrained pastel cues, surfaces = warm cream/beige.
- No scoring engine, points rules, blocking, Focus, privacy, sync or backend behaviour changed.
- Manual Chrome visual acceptance is still required.
