# Project history — Digital Greenhouse to AUREVA

## Digital Greenhouse

Digital Greenhouse began as a Chrome extension concept connecting healthier browsing habits, focus, site protection and personal growth through a virtual plant.

Its intended scope grew into three connected areas:
1. Life Growth — real-life activities, goals, progress and the plant.
2. Digital Awareness — browser activity, context signals and supportive prompts.
3. Digital Protection — site blocking, allowlists, focus and protective redirection.

The project involved multiple implementations and release attempts. The user has explicitly asked that Digital Greenhouse be described as a failed project: it did not reach the intended complete, dependable product outcome. Prototypes, code, tests and individual working features should not be inflated into a successful finished product.

## Transition to AUREVA

AUREVA is the reimagined product identity for Digital Greenhouse within TOLEVU. The plant-centred personal-growth philosophy remains, but the product identity and interface are being reworked.

The most recent AUREVA snapshot in this repository is 0.1.4. The full extension and backend source snapshot is preserved in the developer preview archive, together with tests and project documentation.

## Important release boundary

AUREVA 0.1.4 fixes popup CSP startup, mini-app nested scrolling and visual colour-role placement. It does not alter the scoring engine. Manual Chrome acceptance remains outstanding. The user's reported eight-hour/zero-points experience is therefore retained as an open product issue, not described as fixed.

## Historical artifacts

The existing repository began as a Digital Greenhouse repository and contains an earlier 3.3.1 package. That artifact should be treated as historical. It is preserved on this branch while the project documentation is reorganised.

Do not describe 3.3.1, 4.2.3 or any other package as production-ready solely because an archive exists. Consult the version-specific tests and acceptance notes.
